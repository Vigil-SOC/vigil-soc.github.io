Open source AI SOC Latest release

The open source AI SOC you run yourself.

Specialist agents triage, investigate, hunt and respond beside your analysts, connected to the security tools you already run. Install it with one script and run it in your environment with the model provider you choose.

Get Vigil on GitHub Explore use cases

Licensed under Apache 2.0, with no license key and no registration.

$ git clone https://github.com/Vigil-SOC/vigil.git
$ cd vigil
$ ./start.sh

The script provisions Python, starts PostgreSQL, Redis and the LLM gateway in Docker, and launches the API, the agent layer and the console. The first run takes a few minutes.

$ ./setup_dev.sh   # once: writes the database passwords into .env
$ docker compose --env-file .env \
    -f infra/docker/docker-compose.yml up -d

The default set runs the database, cache, gateway, backup, API and agent layer. Set JWT_SECRET_KEY in .env first. Add --profile daemon for unattended monitoring.

$ helm install vigil ./infra/helm/vigil \
    --namespace vigil --create-namespace \
    --set secrets.anthropicApiKey="$ANTHROPIC_API_KEY" \
    --set secrets.postgresPassword="$(openssl rand -hex 24)" \
    --set secrets.vigilAppPassword="$(openssl rand -hex 24)" \
    --set secrets.jwtSecretKey="$(python -c 'import secrets; print(secrets.token_urlsafe(64))')"

The Helm guide covers values, external Postgres and Redis, ingress and troubleshooting.

$ bash clients/desktop/scripts/bundle-image.sh linux/arm64
$ cd clients/desktop && npm run dist

Builds a macOS DMG or Linux AppImage that packages the stack without a source tree. Docker must be installed and running.

Then open http://localhost:6988

For a tested build, check out a release tag: git checkout v<version>

Architecture

Agents

Built-in specialists cover the core SOC roles. Each is a manifest you can read, fork and rewire, and you can build your own from the console.

Workflows

A workflow is one WORKFLOW.md file: YAML that says what runs, Markdown that explains it. Mark a phase approval_required and it waits for a person.

Skills and workflows you already have

Import skills from a file, a zip or any git repository, popular cyber skills repositories included; Vigil scans and holds each before it runs. Detection rule libraries load the same way. Workflows are Markdown, so playbooks from your SOAR port across as WORKFLOW.md files.

Integrations

Your existing SIEM, EDR, cloud, identity, threat intelligence and ticketing tools connect over MCP, the open standard. Build a new one from API docs with the Custom Integration Builder.

Memory

Prior conclusions are recalled when a run starts and verdicts are written back when it ends, so the learning remains yours, inside your environment.

Optional components

Batteries included, not required

The install above yields a working SOC. Add these components as your needs grow.

DeepTempo's foundation model for security telemetry, connected as one MCP integration among many. Add it as a detection layer when you want one; Vigil does not require it.

SOC daemon

Alert polling, automatic triage and AutoOps for unattended, around-the-clock monitoring. The foreground start leaves it off.

./start.sh -d

Medic

Watches the health, load and headroom of your own install. It changes nothing in Vigil and sends nothing off the machine.

VIGIL_MEDIC_ENABLED=true

Vigil MCP server

Vigil's own SOC operations, served to outside clients and agents: findings, cases, approvals, hunts. Off on a fresh install.

Mission

Security operations shouldn't be a black box you buy. It should be a capability you build, together.

License

Apache 2.0, in full

Vigil is 100% open source. The upstream project has no open core, no license key and no call-home telemetry. OpenTelemetry export stays off until you point it at your own collector.

Principle

Human on the loop

The system can only demote its own autonomy; only people promote it. Proposed actions wait for a person unless your autonomy setting lets the run act.

Team

Built by an AI-native cyber team

The people behind Vigil come from StackStorm, Dragos, Palo Alto Networks and the Allen Institute for AI, among others. They build Vigil with agents in the loop, the way they expect security teams to work.
